# PS5 采集卡 GTA6 30→60 插帧教程

## 一、线路和显示方式

推荐线路是：

```text
PS5 ── HDMI ── 采集卡 ── USB ── Mac 上的 OBS
  └─ HDMI 直通 ── 电视或显示器
```

玩游戏时尽量看 OBS 的“窗口投影（源）”。电视上的直通画面没有经过 OBS，也不会使用插帧滤镜。

## 二、设置 OBS 视频

打开 OBS → 设置 → 视频：

- 基础（画布）分辨率：`1920×1080`
- 输出（缩放）分辨率：`1920×1080`
- 常用 FPS 值：`60`
- 缩放滤镜：`双线性`或`双三次`都可以；插帧主要由光流滤镜完成

采集卡源本身保持 `1920×1080`。如果采集卡有多个模式，优先选择稳定的 30 FPS 输入。可以直接对照 `config/obs-video-settings.example.ini`。

## 三、添加光流滤镜

在“源”列表中选中“视频采集设备”，点击“滤镜”，添加 `Optical Flow Frame Interpolation`。填写：

| 选项 | 推荐值 | 用途 |
|---|---:|---|
| Motion estimation resolution | 1/2 | 提高快速移动边缘的匹配精度 |
| Interpolation strength | 1.00 | 保留完整运动补偿 |
| Artifact protection | 0.65 | 剧烈运动时更积极地压制残影 |
| New-frame detection threshold | 0.10 | 更快识别连续变化的输入帧 |
| Low latency mode | 开启 | 减少一帧额外等待 |
| Debug view | Off | 正常使用时关闭调试画面 |

插件没有中文语言包，所以滤镜面板显示英文，上表左边就是你在面板里看到的原文。OBS 日志里出现 `Failed to load 'zh-CN' text for module: 'obs-optical-flow'` 是正常提示，不影响功能。

配置名称可以写成 `GTA6 高速运动 30→60`，这样以后容易辨认。参数也可以直接对照 `config/filter-settings.example.json`。

## 四、打开插帧后的画面

右键“视频采集设备” → 投影 → `窗口投影（源）`。新窗口显示的就是这个源经过滤镜后的画面。可以把它拖到第二块屏幕，或用绿色全屏按钮放大。

## 五、怎么测试残影

进入游戏后，连续做三组动作，每组观察 20 秒：

1. 快速左右转动视角；
2. 车辆高速转弯并经过建筑、路灯和树木；
3. 在高对比度边缘附近快速晃动镜头。

观察车辆轮廓、人物头部、路灯和字幕边缘。若残影减少且 OBS 状态栏仍然稳定在 `60.00 / 60.00 FPS`，就保留当前配置。

## 六、出现问题时怎么调

- **残影仍然明显**：把插帧强度改为 `0.85`，观察边缘是否更干净。
- **画面像慢慢溶解**：把插帧强度恢复为 `1.00`，并确认输入是稳定的 30 FPS。
- **OBS 出现渲染延迟或掉帧**：把光流分辨率从 1/2 改成 1/4，也就是 `profiles/fallback-low-gpu.json` 里的参数，其余保持不变。
- **快速移动时画面偶尔跳变**：确认低延迟模式开启，并把新帧检测阈值保持在 `0.10`。
- **录制画面正常但投影窗口卡顿**：先降低投影窗口分辨率或关闭其他占用 GPU 的程序。

## 七、验证本机配置

在仓库目录运行：

```bash
python3 scripts/validate_setup.py
python3 scripts/run_optimization.py
python3 -m unittest discover -s tests -v
```

`validate_setup.py` 只读取配置，不会修改 OBS，会逐项打印 17 个检查结果，最后一行显示“通过”或“失败”。它默认读取 `~/Library/Application Support/obs-studio`，可用 `--obs-root` 指向别的位置，或用 `--scene-file` 指定场景文件。修改滤镜前，建议先在 OBS 退出后备份 `~/Library/Application Support/obs-studio/basic/scenes/`。

`scripts/run_plugin_smoke_tests.sh` 需要插件源码树（本机安装的是编译好的 `.plugin`，不含测试源码），用法见 `reports/optimization-results.md`。

## 八、必须知道的限制

插帧是根据前后两帧估算中间画面。快速遮挡、树叶、栅栏、字幕和强烈镜头抖动都可能让估算变得困难，因此它能减少卡顿感，但不能把 PS5 游戏真正改成原生 60 FPS，也不能完全消除所有残影。
